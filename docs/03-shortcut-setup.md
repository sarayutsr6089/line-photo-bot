# ขั้นที่ 3 — แก้ Shortcut เดิมให้ยิงรูปเข้า Worker

ใช้เวลาประมาณ 15 นาที ทำบนไอโฟน

ส่วนที่ **หารูป** ยังใช้ของเดิมทั้งหมด เปลี่ยนแค่ตอนท้ายจาก "Share / Send Message" เป็น "ยิงเข้า Worker"

## 3.0 ก่อนเริ่ม เตรียมไว้ 2 อย่าง

- **URL ของ Worker** จากขั้นที่ 2 เช่น `https://line-photo-bot.arm.workers.dev`
- **INGEST_SECRET** ที่ตั้งไว้

## 3.1 ลบ action เดิมตอนท้ายทิ้ง

เปิด Shortcut "รูปความทรงจำลูก" แล้วลบ action ท้าย ๆ พวกนี้ทิ้ง

- `Send Message`
- `Share`

เก็บส่วนที่หารูปไว้ทั้งหมด (Current Date, Adjust Date, Find Photos, Get Item from List)

## 3.2 หน้าตา Shortcut ที่ควรจะเป็น

เรียงตามลำดับบนลงล่าง

### ส่วนหาวันที่

| # | Action | ตั้งค่า |
|---|---|---|
| 1 | **Date** | Current Date |
| 2 | **Adjust Date** | Subtract `1` `Years` จาก Date → กดค้างตั้งชื่อตัวแปรว่า `Anniversary` |
| 3 | **Adjust Date** | Subtract `5` `Days` จาก `Anniversary` → ตั้งชื่อตัวแปร `StartDate` |
| 4 | **Adjust Date** | Add `5` `Days` จาก `Anniversary` → ตั้งชื่อตัวแปร `EndDate` |

> ของเดิม Arm ตั้ง StartDate เป็นวันครบรอบพอดี แล้วบวกไปข้างหน้า 3-5 วัน แบบนั้นก็ใช้ได้
> แต่แบบข้างบนนี้จะได้ช่วง **ก่อนและหลัง** วันครบรอบอย่างละ 5 วัน โอกาสเจอรูปสูงกว่า

### ส่วนหารูป

| # | Action | ตั้งค่า |
|---|---|---|
| 5 | **Find Photos** | Filter แบบ **All** ทั้ง 3 เงื่อนไข:<br>• `Date Taken` `is after` `StartDate`<br>• `Date Taken` `is before` `EndDate`<br>• `Album` `is` `[อัลบั้มลูก]`<br><br>เปิด **Sort by** = `Random`<br>เปิด **Limit** = `1` |

> เปิด Limit ไว้เสมอ — Arm เจอมาแล้วว่ารูปเยอะเกินแล้วพัง ตอนนี้ตั้ง 1 พอเพราะเราส่งรูปเดียวต่อวัน

### ส่วนเช็คว่าเจอรูปไหม

| # | Action | ตั้งค่า |
|---|---|---|
| 6 | **Count** | Items in `Photos` (ผลจาก Find Photos) |
| 7 | **If** | `Count` `is greater than` `0` |

ทุก action ตั้งแต่ข้อ 8 ถึง 13 ต้องอยู่ **ข้างใน If** (เยื้องเข้าไป)

### ส่วนเตรียมรูปก่อนส่ง — สำคัญมาก ห้ามข้าม

| # | Action | ตั้งค่า |
|---|---|---|
| 8 | **Get Item from List** | `First Item` จาก `Photos` |
| 9 | **Convert Image** | เป็น `JPEG` และ **ปิด** `Preserve Metadata` |
| 10 | **Resize Image** | Width `1280`, Height `Auto` |

**ทำไมต้องมี 3 ข้อนี้**

- ข้อ 9 ไอโฟนถ่ายเป็นไฟล์ HEIC ซึ่ง **LINE แสดงไม่ได้** ต้องแปลงเป็น JPEG ก่อน
- ข้อ 9 การปิด Preserve Metadata จะ **ลบพิกัด GPS** ออกจากรูปก่อนที่รูปจะออกจากเครื่อง — สำคัญเรื่องความเป็นส่วนตัวของลูก
- ข้อ 10 LINE จำกัดรูป preview ไว้ที่ 1 MB ย่อเป็น 1280 แล้วจะเหลือประมาณ 200-400 KB ปลอดภัย และยังคมพอดูในแชท

### ส่วนส่งเข้า Worker

| # | Action | ตั้งค่า |
|---|---|---|
| 11 | **Get Contents of URL** | ดูรายละเอียดข้างล่าง |

กดลูกศรขยาย action นี้ แล้วตั้งค่า

- **URL** — `URL ของ Worker` ต่อท้ายด้วย `/ingest`
  เช่น `https://line-photo-bot.arm.workers.dev/ingest`
- **Method** — `POST`
- **Headers** — กด Add new header
  - Key: `X-Bot-Secret`
  - Value: `INGEST_SECRET ของคุณ`
- **Request Body** — เลือก `Form`
  - กด Add new field → เลือกชนิด **File** (ไม่ใช่ Text)
    - Key: `photo`
    - Value: ผลลัพธ์จากข้อ 10 (`Resized Image`)

> ⚠️ **จุดที่พลาดง่ายที่สุดในทั้งคู่มือ** ถ้าช่อง Value ยังขึ้นคำว่า **`Choose`** สีฟ้าอยู่ แปลว่า
> **ยังไม่ได้เลือกอะไรเลย** — เราสร้างช่องไว้แล้วแต่ยังไม่ได้ใส่ของ พอรันจะได้ error
> `ไม่พบรูปใน request` กลับมา ต้องแตะ `Choose` แล้วเลือก `Resized Image` ให้คำว่า Choose
> เปลี่ยนเป็นชื่อตัวแปรสีฟ้าเสียก่อน
>
> **ถ้าแตะแล้วแอปค้าง** (เจอบ่อย) ให้ปิดแอป Shortcuts ทิ้งแล้วเปิดใหม่ — Shortcuts บันทึก
> อัตโนมัติ สิ่งที่เลือกไปมักไม่หาย ถ้ายังค้างซ้ำ ให้ใช้วิธีลากแทน: แตะ action `Resize Image`
> หนึ่งครั้งให้แถบตัวแปรโผล่เหนือคีย์บอร์ด แล้วกดค้างที่ `Resized Image` ลากมาวางในช่อง
  - กด Add new field → เลือกชนิด **Text**
    - Key: `years`
    - Value: `1`

> **ค่าตั้งต้นคือส่งเฉพาะรูป ไม่มีข้อความบรรยาย** เพื่อประหยัดโควตา 200 ข้อความ/เดือนของแผนฟรี
> ช่อง `years` ที่ใส่ไว้จะยังไม่มีผลอะไร จนกว่าจะเปิด `SEND_CAPTION = "true"` ใน `wrangler.toml`
> พอเปิดแล้ว ข้อความจะขึ้นว่า "เมื่อ 1 ปีที่แล้ว" — แต่จะใช้โควตาเป็นสองเท่า
> ถ้าอยากเขียนข้อความเอง ให้เพิ่ม field ชนิด Text ชื่อ `caption` แทน `years`

### ส่วนเตือนเมื่อส่งไม่สำเร็จ

| # | Action | ตั้งค่า |
|---|---|---|
| 12 | **Get Dictionary Value** | Get `Value` for `sent` in `Contents of URL` |
| 13 | **If** | `Dictionary Value` `is less than` `1` → ข้างใน If ใส่ **Show Notification** ข้อความว่า `ส่งรูปเข้า LINE ไม่สำเร็จ` |

ข้อนี้ทำให้เรารู้ทันทีว่าวันไหนไม่ได้ส่ง แทนที่จะเงียบหายไปเฉย ๆ

### ปิดท้าย

| # | Action | ตั้งค่า |
|---|---|---|
| 14 | **End If** (ของข้อ 7) | ช่อง **Otherwise** ปล่อยว่างไว้ — ไม่เจอรูปวันนั้นก็เงียบไป ไม่ต้องส่งอะไร |

## 3.3 รันด้วยมือ 1 ครั้งก่อน

**ห้ามข้ามข้อนี้** ครั้งแรกที่รัน ไอโฟนจะถามขออนุญาต 2 อย่าง

- ขอเข้าถึงรูปภาพ
- ขออนุญาตส่งข้อมูลไปยังโดเมน `workers.dev`

ต้องกด **อนุญาต/Allow** ทั้งคู่ ถ้าไม่กดตอนนี้ ตอน automation รันเองตอนเช้ามันจะค้างรออยู่แล้วไม่ส่ง

กด **Run** ที่มุมขวาบนของ Shortcut แล้วรอ — ถ้าทุกอย่างถูก รูปจะเด้งเข้า LINE ภายในไม่กี่วินาที

## 3.4 ตั้ง automation

ถ้าตั้งไว้แล้วจากเฟสที่แล้ว ไม่ต้องทำใหม่ แค่เช็คว่าตั้งถูก

1. แอป Shortcuts → แท็บ **Automation** → **+**
2. เลือก **Time of Day** — ตั้งเวลาที่อยากได้รูป เช่น 07:30 น. → **Daily**
3. เลือก **Run Immediately** และ **ปิด** `Notify When Run`
4. เลือก Shortcut `รูปความทรงจำลูก`
5. เช็คให้แน่ใจว่า **Ask Before Running ปิดอยู่**

ถึงตรงนี้ก็เสร็จแล้ว ไม่ต้องกดอะไรอีกเลย

## 3.5 อยากส่งย้อนหลายปีพร้อมกันไหม

ถ้าอยากได้ทั้ง "1 ปีที่แล้ว" และ "3 ปีที่แล้ว" ในวันเดียวกัน ให้ทำสำเนา Shortcut แล้วแก้ 2 จุด

- ข้อ 2 เปลี่ยน `Subtract 1 Years` เป็น `Subtract 3 Years`
- ข้อ 11 field `years` เปลี่ยนจาก `1` เป็น `3`

แล้วตั้ง automation อีกอันคนละเวลา (เช่น 07:30 กับ 07:35) ระวังโควตาข้อความของ LINE แผนฟรีด้วย
