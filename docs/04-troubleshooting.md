# ขั้นที่ 4 — แก้ปัญหาที่เจอบ่อย

## วิธีไล่หาสาเหตุ ให้ทำตามลำดับนี้

ปัญหาเกิดได้ 3 จุด แยกทีละจุดจะหาเจอเร็วกว่าเดามั่ว

```
ไอโฟน (Shortcut) ──1──► Worker (Cloudflare) ──2──► LINE ──3──► แชท
```

### ทางลัด — กด /test ก่อน แล้วจะรู้ทันทีว่าพังฝั่งไหน

เปิด `URL ของ Worker + /test?key= + INGEST_SECRET` ในเบราว์เซอร์

| ผลลัพธ์ | แปลว่า | ไปดูต่อที่ |
|---|---|---|
| รูปทดสอบเด้งเข้า LINE | เซิร์ฟเวอร์กับ LINE ดีหมด **ปัญหาอยู่ที่ Shortcut** | หัวข้อเรื่อง Shortcut ข้างล่าง |
| ไม่เด้ง และเบราว์เซอร์ขึ้น error | ปัญหาอยู่ที่เซิร์ฟเวอร์หรือ LINE | อ่าน error แล้วดูหัวข้อที่ตรงกัน |

### เช็คจุดที่ 2 ก่อนเสมอ — Worker ยังดีอยู่ไหม

เปิดเบราว์เซอร์ไปที่ URL ของ Worker

- **ไม่ขึ้นอะไรเลย / error** → Worker ยังไม่ได้ deploy หรือ deploy ไม่ผ่าน ไปดู log ใน Cloudflare → Workers & Pages → Worker ของเรา → Deployments
- **ขึ้น JSON แต่มี `false`** → ยังใส่ secret ไม่ครบ กลับไป [ขั้นที่ 2.5](02-cloudflare-setup.md)
- **`targetCount: 0`** → ยังไม่ได้ใส่ `LINE_TARGET_IDS` กลับไป [ขั้นที่ 2.7](02-cloudflare-setup.md)

### ดูผลการส่ง 20 ครั้งล่าสุด

```
URL ของ Worker + /status?key= + INGEST_SECRET
```

จะเห็นว่าแต่ละครั้งส่งสำเร็จกี่ปลายทาง และถ้าพังเพราะอะไร ตรงนี้บอกชัดที่สุด

## อาการที่เจอบ่อย

### Shortcut ขึ้น "There was a problem running the shortcut"

ข้อความนี้ไม่บอกว่า action ไหนพัง ต้องไล่แยกทีละอัน

1. ลบ action ตั้งแต่ `Get Contents of URL` ลงไปชั่วคราว แล้วกด Run
   - **ยังพัง** → ปัญหาอยู่ที่ส่วนหารูป ไม่เกี่ยวกับ Worker
   - **ไม่พัง** → ปัญหาอยู่ที่ `Get Contents of URL` ไปดูหัวข้อถัดไป
2. ถ้าพังที่ส่วนหารูป ให้ลบทีละ action จากล่างขึ้นบนจนกว่าจะรันผ่าน อันสุดท้ายที่ลบคือตัวปัญหา

### รันแล้วเงียบ ไม่มีอะไรเข้า LINE และไม่มี error

น่าจะไม่เจอรูปในช่วงวันที่กำหนด (ซึ่งถูกต้องแล้ว ไม่ใช่บั๊ก)

ทดสอบว่าใช่ไหม: แก้ข้อ 3 กับ 4 ใน Shortcut ให้ช่วงกว้างขึ้นชั่วคราว เช่น `Subtract 60 Days` กับ `Add 60 Days` แล้วรันใหม่ ถ้าคราวนี้มีรูปเข้า แปลว่าระบบดี แค่ช่วงวันแคบไป

**ทางแก้ถาวร** เพิ่มช่วงจาก 5 วันเป็น 7-10 วัน หรือเพิ่มรูปเข้าอัลบั้มลูกให้มากขึ้น

### ขึ้นว่า "ไม่พบรูปใน request"

ช่อง `photo` ใน Get Contents of URL ยังไม่ได้ใส่ค่า — ถ้าตรงนั้นยังขึ้นคำว่า `Choose` สีฟ้า
แปลว่ายังว่างอยู่ ต้องแตะแล้วเลือก `Resized Image`

**ข่าวดีของ error นี้:** มันแปลว่า `X-Bot-Secret` ถูกต้องแล้ว (ไม่งั้นจะได้ `secret ไม่ถูกต้อง` แทน)
เหลือแค่ช่องเดียวจริง ๆ

ถ้าแตะแล้วแอป Shortcuts ค้าง ให้ปิดแอปทิ้งแล้วเปิดใหม่ หรือใช้วิธีลากตัวแปรมาวาง
(ดู [ขั้นที่ 3](03-shortcut-setup.md) หัวข้อ Get Contents of URL)

### ขึ้นว่า "รูปใหญ่เกิน 1 MB จึงใช้เป็น preview ของ LINE ไม่ได้"

ยังไม่ได้ใส่ action `Resize Image` หรือใส่ค่ากว้างเกินไป

ไปที่ข้อ 10 ใน Shortcut ตั้ง Width = `1280` ถ้ายังเกินอยู่ให้ลดเป็น `1024`

### ขึ้นว่า "เป็นไฟล์ HEIC ซึ่ง LINE แสดงไม่ได้"

ยังไม่ได้ใส่ action `Convert Image` เป็น JPEG หรือใส่ผิดลำดับ

ลำดับต้องเป็น: Get Item from List → **Convert Image (JPEG)** → **Resize Image** → Get Contents of URL

### ขึ้นว่า "secret ไม่ถูกต้อง" (401)

`X-Bot-Secret` ใน Shortcut ไม่ตรงกับ `INGEST_SECRET` ใน Cloudflare

จุดที่พลาดบ่อย

- คัดลอกมาแล้วติดช่องว่างหน้าหลัง
- ไอโฟนแก้ตัวอักษรตัวแรกเป็นตัวใหญ่ให้อัตโนมัติ
- ชื่อ header พิมพ์ผิด ต้องเป็น `X-Bot-Secret` เป๊ะ ๆ

วิธีที่ชัวร์ที่สุดคือตั้ง secret ใหม่ทั้งสองฝั่งพร้อมกัน

### Worker ตอบว่าส่งไม่สำเร็จ พร้อมโค้ด 403 จาก LINE

แปลว่า LINE ปฏิเสธ สาเหตุที่พบบ่อย

- **ปลายทางยังไม่ได้กด "เพิ่มเพื่อน"** บัญชีบอท — บังคับต้องกด ไม่มีทางลัด
- **บอทถูกเตะออกจากกลุ่มแล้ว** — เชิญเข้าใหม่แล้วให้ใครสักคนพิมพ์ในกลุ่ม 1 ที แล้วเช็ค `/ids` อีกครั้งว่า group id ยังตัวเดิม
- **ปลายทางบล็อกบัญชีบอท** — ให้ปลดบล็อก

### Worker ตอบว่าส่งไม่สำเร็จ พร้อมโค้ด 429

ใช้โควตาข้อความของ LINE แผนฟรีหมดเดือนนี้แล้ว (แผนฟรีไทย = 200 ข้อความ/เดือน)

เช็คโควตาที่เหลือได้ใน LINE Official Account Manager → Insight หรือหน้าหลักของบัญชี
และดูยอดที่ระบบเราใช้ไปแต่ละครั้งได้จาก `/status` ช่อง `lineMessagesUsed`

วิธีลดการใช้โควตา เรียงจากที่ควรทำก่อน

1. ปิด `SEND_CAPTION` (ตั้งเป็น `"false"`) — ลดลงครึ่งหนึ่งทันที
2. ลดจำนวนปลายทางใน `LINE_TARGET_IDS`
3. ลดความถี่ใน automation ของ Shortcut เช่นเหลือวันเว้นวัน หรือสัปดาห์ละครั้ง

### รูปเด้งเข้า LINE แต่เป็นสี่เหลี่ยมเทา กดแล้วไม่ขึ้น

LINE ดึงรูปจาก Worker ไม่ได้

- ถ้าเพิ่งส่งไปเกิน 3 วันแล้ว รูปถูกลบตามกำหนดแล้ว เป็นเรื่องปกติ ของใหม่จะยังดูได้
- ถ้าเป็นรูปที่เพิ่งส่ง ให้ลองเปิด URL รูปนั้นในเบราว์เซอร์ตรง ๆ (ดูจาก `/status`) ถ้าเปิดไม่ขึ้นแปลว่า KV มีปัญหา เช็คว่า Namespace ID ใน `wrangler.toml` ตรงกับของจริง

### Webhook กด Verify ใน LINE Console แล้วไม่ผ่าน

- URL ต้องลงท้ายด้วย `/webhook` และเป็น `https://`
- `LINE_CHANNEL_SECRET` ใน Cloudflare ต้องตรงกับใน LINE Console เป๊ะ ๆ
- ถ้าเพิ่งแก้ secret ต้องกด Deploy ใน Cloudflare ก่อน ค่าถึงจะมีผล

### รูปมาช้ากว่าเวลาที่ตั้ง หรือสองรูปห่างกันไม่เท่าที่ตั้งไว้

**ไม่ใช่อาการเสีย** automation ของ iOS ไม่ใช่นาฬิกาปลุก เป็นแค่การบอกว่า "รันประมาณเวลานี้"
แล้ว iOS ไปจัดคิวเอง เลื่อนได้ตั้งแต่ไม่กี่นาทีถึงหลายสิบนาที โดยเฉพาะตอนเครื่องล็อก
อยู่ในโหมดประหยัดพลังงาน หรือเปิด Focus อยู่ เราควบคุมไม่ได้จากฝั่งเรา

**ผลที่ตามมาที่ต้องรู้:** ถ้าตั้ง automation หลายอันห่างกันไม่กี่นาที ระยะห่างจะไม่ตรงตามที่ตั้ง
และ **ลำดับอาจสลับกันได้** วันไหนที่รูป 2 ปีที่แล้วมาก่อนรูปปีที่แล้วก็ไม่ใช่เรื่องผิดปกติ

**วิธีแก้ถ้าต้องการให้มาติดกันและเรียงถูกเสมอ** อย่าพึ่งเวลา ให้รวมเป็น automation เดียว
สร้าง Shortcut ใหม่ที่มีแค่ action `Run Shortcut` เรียงกันตามลำดับที่ต้องการ

```
Run Shortcut  ->  รูปความทรงจำลูก
Run Shortcut  ->  รูปความทรงจำลูก 2 ปี
```

แล้วให้ automation ตัวเดียวชี้มาที่ Shortcut ตัวนี้ ลบ automation ตัวอื่นทิ้ง
`Run Shortcut` จะรอให้อันแรกเสร็จก่อนค่อยรันอันถัดไป จึงได้ลำดับที่แน่นอน

เวลาที่รูปมาถึงจะยังไม่เป๊ะอยู่ดี ตราบใดที่ยังให้ไอโฟนเป็นคนหยิบรูป

### กลางคืนหรือตอนนอน automation ไม่ทำงาน

ข้อจำกัดที่แลกมากับวิธีนี้ ไอโฟนต้อง

- เปิดเครื่องอยู่ ไม่ได้ปิดหรือแบตหมด
- ต่อ WiFi หรือเน็ตมือถืออยู่
- ไม่ได้เปิด Low Power Mode ค้างไว้นาน ๆ

ถ้าวันไหนพลาด วันถัดไปจะส่งตามปกติ ไม่ต้องทำอะไร

## ถ้าอยากเปลี่ยนอะไรภายหลัง

| อยากเปลี่ยน | ทำที่ไหน |
|---|---|
| เวลาที่ส่ง | Shortcuts → Automation → แก้เวลา |
| ปลายทางที่ส่ง (เพิ่ม/ลดคน) | Cloudflare → Worker → Settings → แก้ `LINE_TARGET_IDS` แล้ว Deploy |
| ช่วงวันที่ค้นหา (±5 วัน) | Shortcut ข้อ 3 กับ 4 |
| ย้อนไปกี่ปี | Shortcut ข้อ 2 และ field `years` ในข้อ 11 |
| เปิด/ปิดข้อความบรรยายที่แนบไปกับรูป | `wrangler.toml` ตัวแปร `SEND_CAPTION` (`"true"` = เปิด ใช้โควตาสองเท่า) |
| ข้อความบรรยายที่จะให้แสดง | เพิ่ม field `caption` ในข้อ 11 ของ Shortcut (ต้องเปิด `SEND_CAPTION` ก่อน) |
| อัลบั้มที่ใช้ | Shortcut ข้อ 5 เงื่อนไข Album |
| อายุที่เก็บรูปบน server (3 วัน) | `src/config.js` ตัวแปร `IMAGE_TTL_SECONDS` แล้ว commit ขึ้น GitHub |

## ถ้าอยากหยุดระบบชั่วคราว

ปิด automation ในแอป Shortcuts พอ ไม่ต้องไปยุ่งกับ Cloudflare

## ถ้าอยากเลิกใช้ถาวร

1. ลบ automation และ Shortcut ในไอโฟน
2. Cloudflare → Workers & Pages → ลบ Worker
3. Cloudflare → KV → ลบ namespace (รูปที่ค้างอยู่จะหายไปด้วย)
4. LINE Developers Console → ลบ channel
