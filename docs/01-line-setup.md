# ขั้นที่ 1 — สร้าง LINE Official Account และเอารหัส 3 ตัว

ใช้เวลาประมาณ 30 นาที

> **ทำบนคอมพิวเตอร์เถอะครับ** บนมือถือทำได้แต่เว็บ LINE จะเด้งไปเด้งมาระหว่างหน้าโฆษณา
> กับหน้าสมัครจริงจนหลงทาง ถ้าจำเป็นต้องใช้มือถือ ให้เปิด "ขอเว็บไซต์สำหรับเดสก์ท็อป"
> ใน Safari ทุกครั้ง และดูทางลัดผ่านแอปในข้อ 1.3

## ภาพรวมว่าจะได้อะไร

สุดท้ายต้องมีของ 3 อย่างนี้ติดมือไปขั้นที่ 2

| ชื่อ | หน้าตา | เอามาจากไหน |
|---|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | สตริงยาวมาก | LINE Developers Console (ข้อ 1.6) |
| `LINE_CHANNEL_SECRET` | สตริงสั้นกว่า | LINE Official Account Manager (ข้อ 1.5) |
| ไอดีบัญชี | เช่น `@907zmyvw` | หน้าแรกของบัญชี ใช้ให้ครอบครัวกดเพิ่มเพื่อน |

## 1.1 สมัครบัญชีนักพัฒนา

1. เข้า https://developers.line.biz/console/ ล็อกอินด้วย **บัญชี LINE ที่ใช้อยู่ทุกวัน**
   (เลือกปุ่ม "Log in with LINE account" ไม่ใช่ Business account)
2. ครั้งแรกจะมีหน้าให้กรอก **Developer name** กับ **Your email** — ชื่อนี้ไม่มีใครเห็น
   ใส่ชื่อตัวเองไปได้เลย
3. ติ๊กยอมรับเงื่อนไข → **Create my account**

## 1.2 สร้าง Provider

Provider คือ "กล่อง" ที่ใช้ใส่บอท LINE บังคับให้มีก่อน

1. กด **Create a new provider** → ตั้งชื่อ เช่น `Arm Family` → **Create**
2. จะเห็นรายการช่องทางให้เลือกสร้าง — กดที่**ตัวหนังสือ** `Create a Messaging API channel`
   (กดที่ตัวหนังสือ ไม่ใช่รูปภาพ เพราะรูปกับข้อความเรียงกันจนแยกยาก)
3. **ตั้งแต่ปี 2025 เป็นต้นมา LINE จะไม่ให้สร้าง channel ตรงนี้แล้ว** แต่จะบอกให้ไปสร้าง
   บัญชีทางการก่อน — ถูกต้องแล้ว ไปทำข้อ 1.3

## 1.3 สร้างบัญชีทางการ (LINE Official Account)

### ทางที่ 1 — ผ่านเว็บ (แนะนำถ้าอยู่หน้าคอม)

1. เข้า https://manager.line.biz โดยตรง (อย่ากดปุ่มจากหน้าก่อนหน้า มันมักพาไปหน้าโฆษณา)
2. ถ้ายังไม่มีบัญชีทางการ จะเห็นปุ่มเขียว **Create LINE official account** → กด
3. ถ้ามันเด้งไปหน้าโฆษณา `lineforbusiness.com` **ไม่ได้หลงทาง** ให้หาปุ่มเขียวทึบ
   **"สมัครบัญชีทางการเลย"** (ไม่ใช่ "ดูราคาแพ็กเกจ" และไม่ใช่ "เข้าใช้งาน") แล้วกด

### ทางที่ 2 — ผ่านแอป (ง่ายกว่ามากถ้ามีแต่มือถือ)

โหลดแอป **LINE Official Account** จาก App Store (ผู้พัฒนา LY Corporation) → ล็อกอินด้วย
บัญชี LINE เดิม → กดสร้างบัญชี — แอปนี้ข้ามปัญหาเว็บเด้งไปมาได้ทั้งหมด

### ฟอร์มที่ต้องกรอก (2 หน้า)

| ช่อง | ใส่อะไร |
|---|---|
| **ชื่อบัญชี** | ชื่อที่ครอบครัวจะเห็นในแชท เช่น `ความทรงจำของลูก` |
| อีเมล | อีเมลตัวเอง |
| ประเทศ | ไทย |
| ประเภทธุรกิจ / หมวดหมู่ | เลือกอะไรก็ได้ที่ใกล้เคียง เช่น อื่นๆ |

> ⚠️ **ชื่อบัญชีห้ามมีคำว่า "LINE" และแก้ไม่ได้ภายใน 7 วันแรก** คิดให้ดีก่อนกดยืนยัน
> ยาวได้ไม่เกิน 20 ตัวอักษร

ช่อง Privacy Policy กับ Terms of Use ที่โผล่มาระหว่างทาง **เว้นว่างได้** (มันเขียนว่า optional)

## 1.4 ตั้งค่าตอนเปิดบัญชีครั้งแรก

หลังสร้างเสร็จจะมีหน้าตั้งค่า 2-3 หน้า

| หน้า | เลือกอะไร |
|---|---|
| **Chat settings** | เลือก **`Off`** — สำคัญมาก ถ้าเลือก On บัญชีจะกลายเป็นแชทที่ต้องพิมพ์ตอบเอง แล้วระบบส่งรูปอัตโนมัติจะใช้ไม่ได้ |
| Profile photo | ใส่รูปอะไรก็ได้ หรือกดข้าม |
| "Start by gathering friends" | กด **`Home screen`** — เราไม่ต้องใช้เครื่องมือการตลาด |

**จดไอดีบัญชีไว้** จะขึ้นใต้ชื่อบัญชีในหน้าแรก หน้าตาแบบ `@907zmyvw`

### เช็คว่าปิดข้อความตอบกลับอัตโนมัติแล้ว

ในแอป LINE Official Account → **Settings** → **Responses** ต้องปิดหมดทุกอัน

| หัวข้อ | ตั้งเป็น |
|---|---|
| Chat | ปิด |
| Greeting message | ปิด |
| Auto-response messages | ปิด |
| **Webhooks** | ตอนนี้ยังกดไม่ได้ (ต้องเปิด Messaging API ก่อน) — **กลับมาเปิดในขั้นที่ 2.7** |

ถ้าไม่ปิด บอทจะเด้งข้อความมั่ว ๆ ตอบทุกครั้งที่มีคนพิมพ์ในกลุ่ม และเปลืองโควตาข้อความด้วย

## 1.5 เปิด Messaging API และเอา Channel secret

1. https://manager.line.biz → กดเข้าบัญชีที่เพิ่งสร้าง
2. **Settings** → **Messaging API** → **Enable** / **ใช้ Messaging API**
3. เลือก provider เป็น **`Arm Family`** (กล่องที่สร้างไว้ข้อ 1.2) ⚠️ อย่าสร้างใหม่
4. หน้า Privacy Policy / Terms of Use → เว้นว่าง → ยืนยัน
5. จะได้ **Channel ID** กับ **Channel secret** → **ก๊อปเก็บไว้ในโน้ตส่วนตัว**

## 1.6 เอา Channel access token

รหัส 2 ตัวข้างบนเป็นเหมือนบัตรประจำตัว แต่ตัวที่ใช้**สั่งส่งข้อความจริง ๆ** คืออีกตัวหนึ่ง

1. กลับไป https://developers.line.biz/console/
2. `Arm Family` → กดเข้า channel ที่เพิ่งโผล่มา → แท็บ **Messaging API**
3. เลื่อนลงล่างสุด หัวข้อ **Channel access token (long-lived)** → **Issue**
4. **ก๊อปเก็บไว้ในโน้ตเดียวกัน**

## 🔐 เรื่องความปลอดภัยของรหัส 3 ตัวนี้

- เก็บในแอปโน้ตส่วนตัวหรือ password manager
- **ห้ามแปะลงในโค้ดหรือ commit ขึ้น GitHub** ขั้นที่ 2 จะสอนวิธีเก็บที่ปลอดภัย
- **ห้ามส่งให้ใคร** รวมถึงห้ามถ่ายรูปหน้าจอที่มีรหัสส่งให้คนช่วยดู
- ถ้าหลุด ให้กด **Issue** ใหม่ใน LINE Console — ตัวเก่าจะใช้ไม่ได้ทันที
