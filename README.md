# รูปความทรงจำลูก → LINE อัตโนมัติ

ส่งรูปลูก "เมื่อ N ปีที่แล้วในวันนี้" เข้า LINE ให้เองทุกวัน โดยไม่ต้องกดอะไรเลย

## ภาพรวมว่าระบบทำงานยังไง

```
iPhone (ทุกเช้า อัตโนมัติ)          Cloudflare Worker (ออนไลน์ 24 ชม.)        LINE
─────────────────────────          ──────────────────────────────────        ────
Shortcut "รูปความทรงจำลูก"
  1. หารูปจากอัลบั้มลูก
     ช่วง ±3-5 วัน เมื่อปีที่แล้ว
  2. สุ่มมา 1 รูป
  3. ย่อรูป + แปลงเป็น JPEG
  4. ยิงเข้า Worker  ────────────►  รับรูป ตรวจขนาด/ชนิดไฟล์
                                    เก็บรูปไว้ชั่วคราว 3 วัน
                                    สั่ง LINE ให้ push  ──────────────────►  เด้งเข้าแชท
                                                                             ทั้งกลุ่มและแชทเดี่ยว
                                    LINE มาดึงรูป  ◄───────────────────────
```

**สิ่งที่ยังทำเหมือนเดิม:** การคัดว่ารูปไหนคือรูปลูก ยังใช้อัลบั้มใน Photos ที่ Arm ทำไว้แล้ว ระบบใหม่แค่หยิบจากอัลบั้มนั้น ไม่มี AI มายุ่ง

**สิ่งที่เปลี่ยนไป:** จากเดิมที่ต้องกดเลือกแชทปลายทางเอง กลายเป็นส่งเองทั้งหมด และส่งเข้าได้หลายที่พร้อมกัน (ทั้งกลุ่ม LINE และแชทเดี่ยว)

## ทำไมเลือกทางนี้

| ทางเลือก | ทำไมไม่เลือก |
|---|---|
| LINE Notify | ถูกยกเลิกไปแล้วตั้งแต่ 31 มี.ค. 2025 |
| Share Sheet ของ iOS | iOS ไม่ยอมให้กำหนดผู้รับล่วงหน้าแล้วส่งเงียบ ๆ เป็นข้อจำกัดระดับ OS |
| อัปโหลดรูปทั้งคลังขึ้น cloud | ต้องย้ายรูปเป็นพัน ๆ ใบ และต้องหาวิธีอัปรูปใหม่เข้าไปเรื่อย ๆ |
| **Shortcut ยิงรูปเข้า server (ที่ใช้อยู่นี้)** | **ต่อยอดจากของเดิมที่ทำงานได้แล้ว ไม่ต้องย้ายรูป ทำน้อยที่สุด** |

ข้อแลกเปลี่ยนของทางนี้: ไอโฟนต้องเปิดอยู่และต่อเน็ตตอนถึงเวลา ถ้าเครื่องดับวันนั้นก็ไม่ส่ง

## ค่าใช้จ่าย

ฟรีทั้งหมด ไม่ต้องผูกบัตรเครดิต

- **Cloudflare Workers** ฟรี 100,000 request/วัน — เราใช้วันละไม่กี่ครั้ง
- **Cloudflare KV** ฟรี 1,000 การเขียน/วัน — เราเขียนวันละ 1-2 ครั้ง
- **LINE Official Account** แผนฟรีมีโควตาข้อความต่อเดือนอยู่หลายร้อยข้อความ — ส่งวันละ 1 รูปเข้า 2-3 ปลายทางยังอยู่ในโควตาสบาย ๆ (เช็คโควตาจริงของแผนที่ใช้ได้ใน LINE Official Account Manager)

## เริ่มติดตั้งตามลำดับนี้

1. [ตั้งค่า LINE Official Account](docs/01-line-setup.md) — สร้างบัญชี เอา token
2. [ตั้งค่า Cloudflare](docs/02-cloudflare-setup.md) — สร้าง Worker แล้ว deploy
3. [แก้ Shortcut เดิม](docs/03-shortcut-setup.md) — เปลี่ยนท้าย Shortcut ให้ยิงเข้า Worker
4. [แก้ปัญหาที่เจอบ่อย](docs/04-troubleshooting.md) — เปิดอ่านเมื่อมันไม่ทำงาน

ใช้เวลาประมาณ 45-60 นาที ทำทีละขั้นได้ ไม่ต้องทำรวดเดียว

## เส้นทางที่ Worker เปิดให้เรียก

| เส้นทาง | ใช้ทำอะไร | ต้องใส่ secret ไหม |
|---|---|---|
| `GET /` | เช็คว่า Worker ยังทำงานและตั้งค่าครบไหม | ไม่ต้อง |
| `POST /ingest` | Shortcut ยิงรูปเข้ามาที่นี่ | ต้อง |
| `GET /i/:id` | LINE มาดึงรูป | ไม่ต้อง (ชื่อไฟล์เดาไม่ได้ และหมดอายุใน 3 วัน) |
| `POST /webhook` | LINE ส่ง event มา ใช้เก็บ user id / group id ให้อัตโนมัติ | ตรวจลายเซ็นจาก LINE |
| `GET /ids` | ดู id ที่เก็บได้ เอาไปตั้งค่าปลายทาง | ต้อง |
| `GET /status` | ดูผลการส่ง 20 ครั้งล่าสุด ไว้ debug | ต้อง |

## เรื่องความเป็นส่วนตัว

รูปลูกเป็นข้อมูลอ่อนไหว ระบบนี้จึงออกแบบไว้แบบนี้

- รูปเก็บบน Cloudflare **แค่ 3 วันแล้วลบอัตโนมัติ** ไม่ได้เก็บถาวร
- URL ของรูปเป็นรหัสสุ่ม 36 ตัวอักษร เดาไม่ได้ และใส่ header กัน search engine เก็บ index
- คลังรูปทั้งหมดยังอยู่ในเครื่องเหมือนเดิม ไม่ได้ย้ายไปไหน มีแค่รูปที่ส่งไปแล้วเท่านั้นที่ผ่าน server
- `/ingest` ต้องมี secret ที่ตั้งเอง คนอื่นยิงรูปเข้าบอทเราไม่ได้
- ผลลัพธ์ที่ตอบกลับปิดบัง LINE id ไว้บางส่วน ไม่ให้ id เต็มหลุดออกไป

## สำหรับคนที่จะแก้โค้ด

```bash
npm install     # ลง wrangler
npm test        # รันเทสต์ (23 เทสต์ ไม่ต้องต่อเน็ต)
npm run dev     # รัน worker บนเครื่อง
npm run deploy  # deploy ขึ้น Cloudflare
```

ไฟล์สำคัญ

- `src/index.js` — ตัวจัดเส้นทาง รับ request ตอบ response
- `src/line.js` — คุยกับ LINE API และตรวจลายเซ็น webhook
- `src/images.js` — ตรวจและเก็บรูป
- `wrangler.toml` — ค่าตั้งของ Cloudflare
